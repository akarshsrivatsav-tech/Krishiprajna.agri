# KrishiPrajna Architecture

## System Flow

```text
Sensors
   ↓
ESP32 Controller
   ↓
WiFi
   ↓
Cloud Backend
   ↓
AI Engine + Database
   ↓
Mobile App + Web Dashboard
   ↓
Farmer
```

## Backend Modules
- Authentication
- Sensor APIs
- Notification Engine
- Irrigation Engine
- AI Prediction System

## Frontend Modules
- Login Page
- Dashboard
- Alerts
- Weather Reports
- AI Assistant
- Water Analytics
- Disease Detection
